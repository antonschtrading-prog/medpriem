# МедПриём — тестовая браузерная версия 0.3

Бесплатный экспериментальный прототип по принципу инженерных калькуляторов: статическая страница GitHub Pages; браузер выполняет локальную обработку аудио. Код программы публикуется открыто. Никаких записей реальных пациентов в репозиторий добавлять нельзя.

## Публикация
Создать **публичный** репозиторий `medpriem` с веткой `main`, загрузить каталог `site/` и `.github/workflows/pages.yml`. GitHub Actions публикует только каталог `site/`. В большинстве случаев `actions/configure-pages` с `enablement: true` включает Pages; если GitHub запретит это политикой репозитория, понадобится выбрать GitHub Actions в Settings → Pages вручную. Не считать адрес опубликованным, пока деплой не прошёл.

## Испытания
Только обезличенная/синтетическая тестовая запись. Загрузить её в интерфейсе, выбрать Tiny для первой проверки запуска модели, затем Base, нажать «Начать расшифровку». Измерить WER/CER по эталонному тексту. Real Whisper еще не протестирован на iPhone.

## Ограничения
Модель Whisper и код Transformers.js пока скачиваются из внешних источников. Несмотря на локальное вычисление, конфиденциальность медицинских записей для реальных пациентов **не подтверждена**. Длинные аудиозаписи могут исчерпать память, особенно Safari на iPhone. Нет автоматического разделения говорящих, DOCX или медицинских заключений.
