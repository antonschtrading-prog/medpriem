# Испытания «МедПриём» 0.3

Сайт предназначен пока только для испытаний на **тестовом аудио без персональных и медицинских данных пациентов**.

## Порядок проверки

1. Откройте сайт GitHub Pages и загрузите короткий тестовый русский WAV/M4A-файл.
2. Выберите Whisper Base и запустите распознавание. Первое скачивание модели может быть долгим.
3. Проверьте текст, таймкоды, числа и медицинские термины.
4. По возможности сравните полученный текст с исходной расшифровкой (WER/CER).
5. После короткого теста переходите к записям 5–10 минут, затем к длинным файлам.

## Не подтверждено

- Реальное качество работы моделей Whisper в Safari на iPhone.
- Скорость и устойчивость обработки файлов длительностью 30–60 минут.
- Гарантии конфиденциальности сторонних библиотек и моделей при реальных данных пациентов.

Используйте только синтетические или разрешённые учебные записи. Этот коммит также запускает повторную публикацию после настройки GitHub Pages на источник GitHub Actions.
