# МедПриём — единый источник требований

## Цель
Бесплатный статический сайт GitHub Pages для локальной расшифровки **русской** речи (разговор врача и пациента). Клиническое применение запрещено до верификации точности, безопасности и конфиденциальности.

## Архитектура
- site/: статический интерфейс JavaScript, браузерный Web Worker, локальное декодирование и сегментация 25 с
- model-options.js: реестр моделей и их семейств
- asr-worker.js: Transformers.js / ONNX WASM для Whisper и русской Wav2Vec2 XLSR
- hallucination.js: обнаружение повторов, единичная попытка нового декодирования, предупреждение
- quality.js: проверка медицинских чисел и терминов, WER/CER при наличии эталона
- checkpoint.js: ручной экспорт/импорт промежуточного результата
- tests/: регрессионные тесты; .github/workflows/pages.yml: CI и Pages

## Нефункциональные ограничения
Нет платных API, серверного хранения аудио, публикации записей в GitHub; запрещено загружать идентифицируемые медицинские записи до независимого аудита внешних зависимостей. Safari/iPhone и модели вне Whisper Base/Small не валидированы в работе с реальным аудио.

## Экспериментальная диаризация v0.5 (отдельная ветка)
- Движок: Sherpa-ONNX WASM через classic Web Worker, pyannote segmentation + speaker embeddings + clustering. Внешние runtime/веса требуют загрузки; информация о медицинских данных не отправляется на сервер намеренно, но третьесторонний runtime ещё не прошёл аудит.
- Временная шкала голосов вычисляется из аудио; привязка к тексту пока консервативная на уровне 25-секундных ASR-сегментов. Невозможно честно выдавать точный диалог до получения более точных временных меток ASR.
- Клиническая эксплуатация остаётся запрещённой до верификации точности, конфиденциальности и внешнего runtime.

## v0.6: новый конвейер (утверждён 25.11.2026)
- Отказ от фиксированных 25-секундных блоков для новых запусков. Старые контрольные точки v1 сохраняют собственный фиксированный формат только при продолжении.
- Основной VAD: Silero NonRealTimeVAD (браузер, ONNX WASM, внешние статические файлы). Резерв: детерминированный локальный акустический поиск пауз по энергии, **это не Silero**.
- Распознавание: Whisper Medium как контрольный вариант; Whisper Large V3 Turbo как новый экспериментальный вариант на базе существующего Transformers.js, без гарантий памяти и скорости.
- Длинная запись разбивается на фрагменты переменной длины с верхним пределом 29 секунд из-за 30-секундного ограничения ASR Worker. При отсутствии пауз возможен вынужденный разрез: целостность слов не гарантирована.
- Диаризация остаётся отдельным акустическим этапом Sherpa-ONNX; результат не считать работающим до браузерного теста. VAD не заменяет диаризацию.
- Точные границы сегментов и результаты сохраняются в checkpoint v2, старые checkpoint v1 поддерживаются в режиме продолжения.
- GigaAM v3 и Qwen3-ASR: кандидаты только после технического подтверждения браузерной реализации. Никаких внешних API распознавания.
