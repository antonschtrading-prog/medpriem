# МедПриём — единый источник требований

## Цель
Бесплатный статический сайт GitHub Pages для локальной расшифровки **русской** речи (разговор врача и пациента). Клиническое применение запрещено до верификации точности, безопасности и конфиденциальности.

## Архитектура
- site/: статический интерфейс JavaScript, браузерный Web Worker, локальное декодирование и сегментация 25 с
- model-options.js: реестр моделей и их семейств
- asr-worker.js: Transformers.js / ONNX WASM для Whisper и русской Wav2Vec2 XLSR
- hallucination.js: обнаружение повторов, единичная попытка нового декодирования, предупреждение
- quality.js: проверка медицинских чисел и терминов, WER/CER при наличии эталона
- checkpoint.js: ручной экспорт/импорт промежуточного результата
- tests/: регрессионные тесты; .github/workflows/pages.yml: CI и Pages

## Нефункциональные ограничения
Нет платных API, серверного хранения аудио, публикации записей в GitHub; запрещено загружать идентифицируемые медицинские записи до независимого аудита внешних зависимостей. Safari/iPhone и модели вне Whisper Base/Small не валидированы в работе с реальным аудио.
